# Python Practice Projects

A collection of small Python projects I built to practice Python syntax, programming patterns, and core language features.

These projects are intentionally built from scratch without following full tutorials. I use hints when needed, but write the implementations myself.

| #  | Project                  | Concepts Practiced                              |
| -- | ------------------------ | ----------------------------------------------- |
| 1  | Basic Profile            | Variables, input, output                        |
| 2  | Calculator               | Input conversion, arithmetic, conditionals      |
| 3  | Grade Calculator         | Conditionals, validation                        |
| 4  | Password Generator       | Loops, `random`, strings                        |
| 5  | Inventory Manager        | Dictionaries, functions, loops                  |
| 6  | Contact Book             | File I/O, dictionaries, persistence             |
| 7  | Log Analyzer             | File parsing, dictionaries, exception handling  |
| 8  | CSV Data Analyzer        | CSV parsing, lists, dictionaries, data analysis |

## What I'm Practicing

* Python syntax and conventions
* Variables and data types
* Conditionals and loops
* Functions
* Lists, dictionaries, and other data structures
* File handling
* Exception handling
* String processing
* Object-oriented programming
* Working with structured data
* Python-specific syntax and built-in functions

## About

I already have programming experience in other languages, so these projects focus primarily on becoming comfortable with **Python syntax, idioms, and standard library features** rather than learning programming fundamentals from scratch.

The projects gradually increase in complexity as I become more comfortable with Python.
