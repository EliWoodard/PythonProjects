# Python Practice Projects

A collection of small Python projects built to practice Python syntax, language features, programming patterns, and standard library functionality.

These projects are intentionally built from scratch without following full tutorials. I use hints when needed, but write the implementations myself.

## About

I already have programming experience in other languages, so these projects focus primarily on becoming comfortable with **Python syntax, idioms, language features, and standard library functionality** rather than learning programming fundamentals from scratch.

The projects are intentionally small and progressively introduce new Python concepts. Rather than following complete tutorials, I build each project independently and use hints only when I get stuck.

The goal is to develop familiarity with the parts of Python that are different from other programming languages and become comfortable reading, writing, and designing Python code.
